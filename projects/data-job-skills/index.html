How it works

  1. Download. A script fetches 36 monthly threads from the public Hacker News search API.
  2. Parse. Each job post is cleaned and searched for 4 roles and skills with hand-written patterns. The findings go into a SQLite database; the text does not.
  3. Query. Every count on this page comes from a SQL query in analysis/queries.sql.
  4. Test. Shares get 95% intervals. Comparisons are tested and corrected for the number of tests.

What this cannot tell you

  • These are mostly start-ups and software companies, and mostly senior jobs. A bank or a hospital hires differently, and R is far more common there than here.
  • A post usually lists several jobs. I cannot tell which skill belongs to which job, only which skills travel with which role.
  • A mention is not a requirement. “Experience with SQL a plus” and “SQL expert” count the same.
  • The patterns miss some wordings and catch some wrong ones. I read random matches for the ambiguous skills and tightened them; the report lists what I changed.
