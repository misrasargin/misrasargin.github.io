      How it works, in plain words

      The question

      Do some countries give each other more points than the song deserves?

      The data

      Every grand final vote since the 12-point system began in 1975. Open dataset by Spijkervet and Burgoyne.

      The measure

      Bias: the points A gave a song, minus the average the rest of Europe gave that song that year. A great song gets points from everyone, so quality cancels out.

      The test

      Shuffle the voters, recompute, repeat. If real bias beats almost every shuffle, it is not luck. Then correct for testing many pairs.

      What this cannot tell you

      • It shows that pairs favour each other, not why. Shared language, diaspora, shared music taste and politics all look the same in this data.
      • Pairs need at least shared finals to be tested, so newer countries are under-represented.
      • The shuffle treats each song separately. It ignores that a voter has only one 12 to give, which makes the test slightly approximate.
      • Bias is not the same as deciding the winner. A few extra points from friends rarely change who wins.
